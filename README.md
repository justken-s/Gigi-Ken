# 🌌 Nuestra Constelación - Gigi

Este proyecto es un regalo especial para celebrar nuestros **6 meses juntos** (4 de mayo). 

### ✨ ¿Qué es?
Es un mapa estelar interactivo donde cada estrella es un recuerdo real de nuestro camino. Incluye:
- ⏳ **Contador dinámico:** Tiempo exacto desde el 4 de noviembre de 2025.
- 🎵 **Ambiente:** Música de fondo para acompañar el recorrido.
- 📸 **Galería:** Muchos momentos únicos capturados en fotos.
